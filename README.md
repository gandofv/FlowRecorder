# 步录 · 桌面流程录制器

在主显示器上录一串鼠标左键单击，保存成 JSON，下次从相同起始页面回放。适合由菜单、标签和按钮组成的桌面导航流程。

## 第一次启动

先完整解压，在本机安装带 Tk 的 Python。建议使用 python.org 的 Python 3.11 或 3.12（Apple 芯片选择 macOS universal2，Windows 安装时包含 Python Launcher）。第一次运行需要联网下载依赖，之后在本地运行。

- **Mac**：双击 `Start.command`。也可以打开终端，输入 `bash `（末尾留一个空格），把 Start.command 拖入终端，按回车。首次按系统提示，在「系统设置 → 隐私与安全性」为实际启动程序（例如终端或 Python）开启屏幕录制、辅助功能及所需的输入监控，然后彻底退出并重新打开启动程序。
- **Windows**：双击 `Start.cmd`。目标应用和录制器都以普通用户身份运行。若提示找不到 py，请安装上述带 Python Launcher 的版本。
- 第一次启动若失败，从终端运行对应入口查看依赖安装信息。可用 `python3 -m tkinter`（Windows 用 `py -3 -m tkinter`）检查 Tk。

## 录制与使用

1. 将目标程序放在主显示器，打开希望作为起点的页面。保持桌面无遮挡。
2. 点「录制新流程」并确认。录制器将最小化，3 秒内切换到目标应用。听到提示音后开始单击。每次先等页面稳定，鼠标在按钮上短暂停留再点。
3. 按 **F8** 结束；部分 Mac 键盘需要 **Fn + F8**。也可以切回工具并点击「停止」。尽量使用快捷键，避免切换窗口的点击被录入。选择每一步可以查看实际保存的定位图，并修改名称和点击前等待时间。删除多余的结尾步骤。
4. 点「保存」。需要下次直接运行时，再点「生成快捷脚本」。在同一台机器上，双击生成的 .command 或 .cmd，确认并在倒计时内回到起始页面。快捷入口引用本机项目和 JSON 的绝对路径；移动后重新生成。
5. 若某一步失效，将应用手动移到该步骤的前一页，回工具选中该步，点「重录此步」。倒计时后单击新按钮即可，原步骤名与等待时间会保留。保存后快捷脚本会使用修改后的流程。

**微信示例**：先在桌面微信确认这些入口可点击，再从首页录到你需要的页面。例如依次点「我」「钱包」「余额」，在余额页面按 F8。不同系统和微信版本显示的入口可能不同，请以实际界面为准。脚本结束表示最后一次点击已发送；程序不会读取余额或验证页面业务结果。

## 能力范围

- 录制主显示器、同一前台应用中的左键单击；不支持键盘输入、滚动、拖动、双击手势或跨应用流程。
- 每一步保存点击前最多 105 × 57 逻辑像素的图块、图块内点击位置、名称和等待时间。全屏画面仅在处理期间存在内存中；脚本中的局部图块可能包含附近的昵称或金额，分享前可在界面预览。
- 回放允许窗口平移。保持相同的主题、显示缩放、字体大小和语言；动态文字、悬停样式、重复按钮会影响匹配。页面改变时最多等待约 10 秒，无法唯一匹配就停止。录制普通导航步骤时建议选择图标和稳定的文字。
- macOS 和 Windows 分别录制；UI 外观、前台应用身份不同。Windows 使用可执行文件路径，macOS 使用应用标识。Windows 应用搬迁后需重新录制。
- 这是源码发行包；两端均需要本地 Python。包内测试使用合成画面及模拟设备，可在安装依赖后执行 `python -m unittest -v`。

## 维护

| 文件 | 职责 |
| --- | --- |
| app.py | Tkinter 中文界面、步骤预览与编辑、快捷脚本 |
| engine.py | 倒计时、点击前取帧、录制、逐步回放与中止 |
| desktop.py | 平台前台窗口识别、遮挡检查、显示坐标与点击 |
| flow.py | 图像定位、JSON v1 格式校验与原子保存 |
| test_flow.py / test_engine.py | 定位、读写、回放和中止回归测试 |

界面与后台工作线程通过消息队列通信。pynput 监听单击与停止键，PyAutoGUI 截屏并回放，Pillow 与 NumPy 匹配按钮附近的图像。JSON 只保存流程数据，无需修改 Python 即可改名或调整等待时间。
